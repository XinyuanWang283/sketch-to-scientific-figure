# Security and privacy

## Reporting a vulnerability

Please use GitHub's private security-advisory flow for vulnerabilities that could expose files, credentials, or local execution environments. Do not include secrets, private manuscripts, unpublished data, patient information, or other confidential material in a public issue.

For ordinary correctness bugs that do not involve sensitive material, open a GitHub issue with a minimal fictional reproduction.

## Local-execution boundary

The repository runs local scripts and optional document-conversion tools. Review commands and input files before execution. Keep credentials outside the repository, verify the provenance and license of visual assets, and use a new run directory when processing sensitive work.
